# P2 見本データで使った名前の一覧

- 作成：2026-10-11（researcher）
- 対象：`dist/genka-keisan.xlsx`（全5シート：使い方／材料マスタ／メニュー原価／一覧／設定）と `dist/README.txt`。
- 確認の方法：openpyxl で全シートの全セル（数式を除く文字列）、入力規則（リスト）、ファイルのプロパティ（docProps/core.xml、app.xml）、フォント名（styles.xml）、ヘッダー・フッターを取り出し、目で確認しました。あわせて次の文字を grep しました。
  - 人名の手がかり：様、さん
  - 住所の手がかり：〒
  - 電話番号の形：数字-数字-数字
  - 会社・ブランドの手がかり：株式会社、®、™、@
- 結果：
  - 見本の固有名詞は、表 A の店名「〇〇食堂（見本）」だけです。
  - 人名・住所・電話番号・メールアドレス・実在の店名は 0件です（上の grep は README.txt・xlsx とも 0件）。
  - ヘッダー・フッターは設定されていません。
  - 見本以外の固有名詞として、表 D のソフト名・フォント名・ファイルの作成者名（MenuBridge）があります。

## 実在・商標の確認（researcher, 2026-10-11）

### 1. 実在の店舗との一致（WebSearch、検索日 2026-10-11）

| 検索語 | 該当の有無 | 主な結果とURL |
|---|---|---|
| `"〇〇食堂"` | 「〇〇食堂」という名の店は見つからず | 「地名＋食堂」型の店名の例（まいどおおきに食堂 https://ranking.net/items/05d66c ）や、食べログの「食堂」一覧（https://tabelog.com/tw/R8708/rstLst/teishoku/38/ ）が出ただけ |
| `"○○食堂" 店舗` | 同上 | 熊本市の助成金申請書の記載例で「○○食堂」が伏せ字として使われている（https://www.city.kumamoto.jp/kiji0034849/5_4849_351222_up_RY2407HD.pdf ）。ほかは別名の店（食堂くく https://hamoni.jp/shop/0PqbMKJCcs3v29kLekfB 、最強食堂 https://aumo.jp/articles/45315 など） |
| `"まるまる食堂"`（「〇〇」の読み） | 完全一致の店は見つからず | 似た名前の別店（まるみ食堂 https://retty.me/restaurant/100001346910/ 、まるは食堂 https://epark.jp/shopinfo/jsp629799/ など）。どれも「まるまる食堂」ではない |

- 判断：「〇〇食堂（見本）」と一致する実在の店は、検索の範囲では見つかりませんでした。公的な書類でも「○○食堂」は伏せ字（記入例）として使われています。
- 限界：WebSearch は米国向けの検索で、日本の個人店を網羅していません。「見つからなかった」は「存在しない」の証明ではありません。

### 2. 登録商標（J-PlatPat）

- J-PlatPat は環境から接続できませんでした（2026-10-11）。
  - WebFetch `https://www.j-platpat.inpit.go.jp/` → `getaddrinfo ENOTFOUND www.j-platpat.inpit.go.jp`
  - curl（プロキシ経由）→ `curl: (56) CONNECT tunnel failed, response 403`
- 代替の WebSearch（2026-10-11）：
  - `"〇〇食堂" 商標登録 J-PlatPat` → 商標の情報は出ず、「食堂」の辞書の説明だけ（https://kotobank.jp/word/食堂 など）。
  - `"Sample" "Shokudo" restaurant name trademark` → 米国の登録例（HONOLULU SHOKUDO https://trademark.justia.com/863/83/honolulu-86383109.html 、SHINYA SHOKUDO https://trademark.justia.com/900/73/shinya-90073094.html ）では、"SHOKUDO" の部分は一般語として権利の対象から外されている（ディスクレーム）。「〇〇食堂」「Sample Shokudo」そのものの登録は見つからず。
- 根拠（商標の問題がないと考える理由）：
  - 「〇〇」は伏せ字の記号で、特定の名前を指しません。「食堂」は一般名詞です。
  - どの場所でも「（見本）」を併記し、「実在の店や商品の価格ではありません」と書いています。
  - 商品名・ロゴ・出品タイトルには使いません（商品名は「原価率計算シート（個人経営の飲食店向け）」）。
  - ※以上は推測を含みます。J-PlatPat で直接確認したものではありません。
- 料理名・材料名（表 B・C）は一般名詞のため、個別の検索はしていません。

### 3. MenuBridge（ファイルのプロパティ「作成者」）

- WebSearch `"MenuBridge" OR "メニューブリッジ" 商標`（2026-10-11）→ 商標登録・出願を示すページは見つからず。似た名前の別サービス（MenuNet https://restaurantleadership.com/company/trabon 、Menutech https://menutech.com/llms.txt など）だけでした。
- J-PlatPat では確認できていません（上と同じ理由）。
- 「MenuBridge」は当社の仮の社名で、見本ではありません。今後、屋号・ショップ名として使うなら、創業者が J-PlatPat（区分 第9類・第35類・第42類など）で確認してから使うのが安全です（推測）。それまでは、プロパティの作成者を空欄か一般的な表記にする案もあります。判断は創業者・engineer に任せます。
