# company.md — 会社の定義

> 一人社長カンパニー・プロンプト（`prompts/one-person-company.md`）に沿って運営する。
> 実行ループの起点。毎サイクル最初に読む。

## 会社

| 項目 | 内容 |
|---|---|
| 仮の社名 | **MenuBridge（メニューブリッジ）** |
| 事業 | 小規模飲食店向けの業務テンプレート（Googleスプレッドシート／Excel／印刷用HTML）のデジタル販売。集客用に無料の小型Webツールも作る |
| 顧客 | 個人経営・小規模の飲食店の店主と店長 |
| 販路 | BOOTH（主力）。Gumroad と note は第2段階 |
| 価格（仮説） | 1商品 980〜2,980円。セット割あり |
| 週次目標 | `progress.md` の「次のアクション」に従う |
| 予算上限 | 10万円。支出は創業者の承認が必要 |
| 実行制限 | 週1回の定期実行（月曜 8:50 JST）。1回あたりの新商品は最大3点 |
| 創業者の役割 | 口座・アカウント作成、承認キュー（`approvals.md`）の処理。月1回程度 |

- 選定の理由は `research/hands-off-selection.md` を参照。
- 第1週の受託案（店舗営業型）は、創業者の営業が必要なため**休止**。成果物（`product/sample-menu/`、`sales/`）は商品の素材として再利用する。

## 組織

`org/README.md` を参照。エージェントの定義は `.claude/agents/`。

## ノード

| ノード | オーナー | 出力（測定可能） | チェック |
|---|---|---|---|
| リサーチ | researcher | 商品案（誰の、どの作業を、何分短縮するか）、競合価格 | 出典URLがある |
| 制作 | designer＋engineer | 商品ファイル一式 | 計算式のテスト結果がある。スマホとA4で読める |
| コンテンツ | writer | 販売ページ文、同梱マニュアル | 誇大表現がない。規約の表示がある |
| マーケティング | marketer | 出品情報（タイトル、タグ、価格）、販売分析 | 販売データと整合している |
| 品質ゲート | qa | 判定（続行／修正／証拠不足） | 全7項目を判定している |
| 組織 | recruiter | 新しい役職の提案 | 権限が最小限 |
| 財務 | コードノード | 売上・手数料・支出・予算残（`finance/sales.md`） | 合計が一致する |
