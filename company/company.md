# company.md — 会社の定義

> 一人社長カンパニー・プロンプト（`prompts/one-person-company.md`）に沿って運営する。
> このファイルは実行ループの起点。毎サイクル最初に読む。

## 会社

| 項目 | 内容 |
|---|---|
| 仮の社名 | **メニューブリッジ（MenuBridge）** |
| プロダクト | 個人飲食店向け 多言語メニュー制作（日本語／英語／中国語簡体字／韓国語）。QRで開くWebページと印刷用データを納品 |
| 顧客 | 訪日客が来る地域の、予約SaaSを使っていない個人経営の飲食店（席数30以下） |
| 価格（仮説） | 初回制作 19,800円（40品まで）／品目の追加・変更 1品500円／月額なし |
| 週次目標（第1週） | 事業を決める。デモを1つ作る。営業の準備を整える |
| 予算上限 | 10万円（**第1週の支出は0円**） |
| 実行制限 | 1サイクル＝1週間。創業者の承認が必要な時点で停止する |

選定の理由は `research/idea-selection.md` を参照。

## グラフ（ノード一覧）

```
            ┌────────────┐
            │  リサーチ   │ 市場・競合・顧客の声
            └─────┬──────┘
                  ▼
┌────────┐   ┌────────────┐   ┌────────┐
│  営業  │──▶│ 制作（開発）│──▶│ サポート │
└───┬────┘   └─────┬──────┘   └────────┘
    │              │
    ▼              ▼
┌────────┐   ┌────────────┐
│コンテンツ│   │    財務     │
└────────┘   └────────────┘
```

| ノード | オーナー | 入力 | 出力（測定可能） | チェック |
|---|---|---|---|---|
| リサーチ | Claude | 公開データ、店主ヒアリング | 候補比較表、仮説リスト | 出典URLがある。仮説と事実を分けている |
| 制作 | Claude（翻訳・HTML）＋創業者（最終確認） | 店のメニュー写真・品目リスト | 多言語メニューのWebページと印刷用データ | 全言語で全品目がそろう。アレルゲンが店主確認済み |
| 営業 | 創業者（訪問・連絡）＋Claude（台本・リスト条件） | ターゲット条件 | 接触数、デモを見せた数、受注数 | 送信・訪問は創業者のみが行う |
| コンテンツ | Claude | 制作事例 | LP、事例紹介 | 誇大表現がない。価格が company.md と一致 |
| サポート | Claude（下書き）＋創業者（返信） | 店主からの修正依頼 | 修正の完了数、対応時間 | 48時間以内に対応 |
| 財務 | コードノード | 受注・支出 | 売上・粗利・支出の表 | 合計が一致する。予算内に収まる |

## コードノード（AIに判断させない処理）

- 品目数 × 単価の見積もり計算（`finance/unit-economics.md` の式）
- 全言語で品目数がそろっているかの検査（デモページ内の自動チェック）
- 支出合計と予算上限の比較
