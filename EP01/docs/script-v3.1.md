# EP01 台本 v3.1｜携帯がない時代、待ち合わせに遅れたらどうしてた？

- 基準：v3（約1,170字）を、声に出して自然か・反復がないか・史実と架空が混ざっていないかの観点で整えたもの
- 本文：字幕ベースで約1,050字。**実音声の尺は 3分07秒**（Kokoro `jf_alpha`、話速1.0倍、文間0.15〜0.8秒）
- 正本は `src/beats.py`。ここに書いた文と食い違う場合は `beats.py` が正しい

## v3 → v3.1 の変更点

| 箇所 | v3 | v3.1 | 理由 |
|---|---|---|---|
| 再現の宣言 | 「1980年代後半を想定して…再現してみます。ここからの人物と出来事は、架空の例です。」の2文 | 「1980年代後半を想定した、架空の二人で再現してみます。」1文＋画面の「架空の再現」表示を常時表示 | 同じ断りを2回言わないため。画面表示は再現パートのあいだずっと残る |
| 家族経由の伝言 | 「公衆電話から家族に伝えてもらう方法は考えられます。でも、待つ側も家へ電話するなど…」 | 「遅れる側が、公衆電話から自分の家に伝言を頼む手もあります。ただ、待つ側がその家へ電話しない限り、伝言は届きません。」 | 「誰の家族か」「誰が誰に電話するか」が曖昧だった |
| 伝言板の文面 | 「これは使い方を示す架空の文面です。」と読み上げ | 読み上げをやめ、画面に「※文面は説明用の例です」を表示 | テンポのため。断り自体は画面に残す |
| 撤去時期の一文 | 1文（読み上げ12秒） | 字幕2枚に分割 | 1枚の字幕が長すぎて読めない |
| 「改札の中？外？…」 | — | 変更なし | — |

## ナレーション全文と画面

時刻は完成動画のもの。**太字**は画面上部の大見出し。

### 0:00 冒頭：連絡できない（hook）
- 待ち合わせに、30分遅刻。 — **30分遅刻。** 時計の針が30分進み、その範囲が赤く塗られる。遅れた人が走り込む
- でも、「ごめん、遅れる」が送れません。 — **「遅れる」が送れない** 吹き出し「ごめん、遅れる」に赤線、「送れない」
- 携帯を持っていない二人は、どうやって会っていたのでしょう。 — 時計が縮んで左上へ。待つ人が現れ、二人の間に点線と×付きの携帯「携帯なし」

### 0:10 電話はある。でも本人がいない（phone）
- 「公衆電話から、かければいいのでは？」 — **公衆電話なら？**
- ところが、相手はもう家を出ています。 — **相手は、もう外。** 家（戸が開いている）から相手が駅へ歩く。「留守」
- 家の電話を鳴らしても、駅で待つ本人は出られません。 — **本人には届かない** 公衆電話→家の矢印。家の電話が鳴る。家→本人の点線が途中で×
- 電話はある。でも、かける先に本人がいない。 — 公衆電話に✓「電話はある」、家に×「本人がいない」
- ここが、今の待ち合わせとの大きな違いです。 — 比較カード「当時：電話は『場所』にかける／今：電話は『人』にかける」

### 0:27 再現の宣言（recon）
- 1980年代後半を想定した、架空の二人で再現してみます。 — 「再現」「1980年代後半を想定・架空の人物」。待つ側（緑）と遅れる側（橙）を紹介。以後、左上に「架空の再現」

### 0:34 約束の場所（plan）
- 午後2時、駅で待ち合わせ。 — **午後2時、駅で。** 駅舎（時計は2時）と二人
- ただし、「駅で」だけでは心配です。 — **「駅で」の、どこ？**
- 改札の中？ 外？ 東口？ 西口？ — 駅の見取り図。読み上げに合わせて4つの札が順に出る
- 今なら「ここにいる」と写真を送れます。でも、この二人にはできません。 — スマホに「ここにいる」と写真 → ×
- そこで、「東口の改札を出て、時計の下」と決めました。 — 改札から東口の時計へ矢印、丸囲み「約束の場所」

### 0:52 当日（missed）
- ところが当日、一人が電車を逃してしまいます。 — 電車が発車し、遅れる側が走り込んで「乗り遅れ！」
- 待つ側には、何も届きません。 — 時計の下で待つ人、時計は2:00→2:10、「……」「連絡なし」
- 遅れている？ 場所を間違えた？ 忘れた？ — 2:15。考えの吹き出しが読み上げに合わせて3つ

### 1:02 動くか、待つか（dilemma）
- 別の出口を探しに行けば、会えるかも。 — 見取り図上で待つ側が西口へ向かう
- でも、自分が動いた間に相手が来たら？ — 遅れる側が東口の時計の下に到着、「入れ違い」
- 二人とも探し回ると、かえってすれ違うかもしれません。 — 二人が逆方向に回り続ける「すれ違い」

### 1:12 家経由の伝言（relay）
- 遅れる側が、公衆電話から自分の家に伝言を頼む手もあります。 — 公衆電話→遅れる側の家、家族の吹き出し「伝言：30分遅れる」
- ただ、待つ側がその家へ電話しない限り、伝言は届きません。 — 待つ側→家への灰色の点線「待つ側が電話すれば…」「かけなければ届かない」
- 事前に決めていなければ、伝わる保証はありません。 — カード「事前の相談『遅れたら家に電話して』」に×

### 1:27 駅の伝言板（board）
- そこで使われた道具の一つが、駅の伝言板。 — 改札と伝言板（黒板）
- 改札横や待合室の黒板に、相手への言葉を残す方法です。 — 「改札横」「待合室にも」
- 「東口で待っています」。あるいは、「先に喫茶店へ行きます」。 — 読み上げに合わせてチョークの文字が書かれる。「※文面は説明用の例です」
- 相手が板を見れば、居場所が分かる。 — 遅れる側が板を読み「東口だ！」

### 1:45 今との比較（compare）
- ただし、通知は来ません。既読も付きません。 — 左：伝言板「通知なし」「既読なし」／右：スマホの通知と既読
- 周りの人にも読めます。 — 伝言板の周りに目のアイコン、右「読むのは本人だけ」
- 今のメッセージとは、ずいぶん違いますね。 — 「当時：伝言板｜今：メッセージ」

### 1:54 結末（reunion）
- 今回の二人は、30分遅れで会えました。 — 時計2:30、遅れる側が到着「ごめん！」「よかった！」
- 待つ側が、約束した時計の下から動かなかったからです。 — 足元の丸囲み「動かなかった」
- もし違う出口へ探しに行っていたら、結末は変わったかもしれません。 — 「もしも…」待つ側が半透明で去り、遅れる側「いない…」
- 連絡できないからこそ、出かける前の約束が二人を助けます。 — カード「出かける前の約束」
- 場所、時間、会えなかった場合の行動。 — 読み上げに合わせて3項目にチェック

### 2:15 注意（caveat）
- もちろん、時代や地域、人によって、使った方法は違います。 — 時代・地域・人のアイコン「使った方法は、さまざま」
- 伝言板があった駅も、なかった駅もあります。 — 「伝言板あり」「伝言板なし」の2駅

### 2:23 その後（history）
- その後、ポケベルや携帯が広まりますが、伝言板が全国一斉に消えたわけではありません。 — 年表。ポケベル・携帯が出る「全国一斉に消えた？」×
- 日本地理学会の発表要旨では、使われ方の変化などにより、 — 出典カード（片山 2016）
- 一部の鉄道会社で1990年前後から撤去が始まったと報告されています。 — 年表の1990年前後にピン、伝言板の帯が薄くなる「一部の鉄道会社で撤去が始まる」
- 「携帯が普及したから」だけでは、説明できないのです。 — 「携帯の普及 ＝ 伝言板が消えた理由？」の＝に×「それだけでは説明できない」

### 2:48 今（now）
- 今は、家を出たあとも約束を変えられます。 — 外にいる二人がスマホでつながる
- 「あと5分」「店に入ってる」。 — スマホに2つのメッセージが読み上げに合わせて出る
- たった一言が、待ち合わせの不安を減らしています。 — 「不安が減る」

### 2:58 問いかけ（cta）
- あなたは携帯を持つ前、どこで待ち合わせていましたか？ — 「改札前？」「時計の下？」「お店？」「コメントで教えてください」
- 当時を知らない人なら、何分まで待てそうですか？ — 時計が回り続ける「何分まで待てる？」
