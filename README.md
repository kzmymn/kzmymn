# kzmymn

## keyboard-asmr（3DキーボードASMR・試作）

インスタリール向けの縦型（9:16）、10秒ループのショート動画用の試作です。

- 見た目：Y2Kのスケルトン・キャンディ（半透明のキー、透明ケース、中の基板とバネが見える）
- キー：4×2の8キーを寄りで撮る
- 打ち方：ランダムにカチカチ打つ（「別のパターン」ボタンで打ち方を変更）
- 音：今は合成音。`keyboard-asmr/index.html` の `SAMPLE_URLS` に録音ファイルを指定すると差し替えられる

### 仕組み（動きと音がズレない理由）
「楽譜」（何秒にどのキーを押すか）を1つだけ作り、キーの動きと音の両方がそれを見て動きます。
