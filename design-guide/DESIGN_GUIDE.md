# 資料デザインガイド

今後の資料（提案書・レポート・スライド）作成時に参照するデザイン指針。
以下2つの参考資料を分析して作成した。

| ID | 参考資料 | 性格 | 使いどころ |
|----|----------|------|-----------|
| **A** | 大手飲料メーカー向け提案資料（Knowns / 46枚） | 明るい・清潔・ロジカル。白地＋ティール | 営業提案書、分析レポート、クライアント向け説明資料 |
| **B** | EVENT MARKETING REPORT #2（NewsPicks / 40枚） | 重厚・エディトリアル・ブランド感。グラデーション＋オレンジ | 調査レポート、ホワイトペーパー、ブランディング色の強い資料 |

迷ったら **A をベース**にし、表紙・章扉・メッセージスライドだけ **B のエディトリアル表現**を借りる。

---

## 1. 共通の基本仕様

- **サイズ**: 16:9（720 × 405 pt / 1920 × 1080 px）
- **作成ツール想定**: Google スライド（両資料とも Google 製）
- **余白**: 左右 約 5%（36pt前後）。本文エリアは中央寄せでゆったり
- **1スライド1メッセージ**: 上部に「結論を言い切るキャッチ」を置き、下に根拠（図・数値）
- **ページ番号**: 右上（A）または右下（B）に小さく
- **フッター**: 右下にロゴ＋コピーライト（`© 2025 ○○ Inc.`）を極小サイズで

### 構成テンプレート（両資料共通の流れ）
1. 表紙
2. 問題提起（課題・痛み）→ 解決後の世界（01/02/03 の3点）
3. 目次（Index）
4. 章扉 `01` → 本編（分析・データ）→ 章まとめ
5. 章扉 `02`, `03` …
6. 総括メッセージ
7. 会社紹介・サービス・料金プラン・事例
8. 今後の流れ / CTA（「日程調整はこちら」など）
9. 会社概要・体制 → ミッション（エモーショナルな締め）

## 2. スタイル A：クリーン＆ティール（提案書向け）

### カラー
| 役割 | 色 | HEX |
|------|-----|-----|
| メイン（ティール） | ■ | `#3B95A9` |
| メイン濃 | ■ | `#398C9D` |
| メイン淡（帯・背景） | ■ | `#D7EAEE` |
| メイン中間 | ■ | `#6FB6C6` / `#9CCED7` |
| テキスト | ■ | `#2A2C28`（ほぼ黒） |
| サブテキスト | ■ | `#5E5E5C` / `#A2A3A2` |
| 背景 | □ | `#FFFFFF`（カードは `#F7F9FA` 程度の淡いグレー） |
| アクセント（STEP色分け用） | ■ | ティール `#3B95A9` / グリーン `#5AAE8C` / コーラル `#FC7D78` / オレンジ `#F0A030` |

- 強調語は**ティール文字**、注意・比較対象は**コーラル**。
- 表のハイライトは淡いグリーン（良い）／淡いピンク（悪い）セル塗り。

### タイポグラフィ
- 和文: **Zen Kaku Gothic New**（Regular / Medium / Bold / Black）、補助に Noto Sans JP
- 欧文・数字: **Lato**（Light / Regular / Bold）
- 字間をやや広め（トラッキング +50〜100）にして上品に
- サイズ目安: キャッチ 24–28pt Bold／見出しラベル 11–12pt／本文 10–12pt／注釈 7–8pt
- 表紙・問題提起は 36–44pt Black の大見出し。キーワードを “ ” で括り、下線で強調

### レイアウト要素
- **ページ見出し**: 左上に縦線 `|` ＋「章名｜小見出し」（小さめ、黒）
- **キャッチ**: 中央揃え、1〜2行。2行目の後半をティールで強調
  - 例:「スポーツドリンク市場は拡大 / だが、**伸びている理由はひとつではない**」
- **セクションラベル**: 左にティールの太い縦棒＋太字（例 `▍市場規模`）、またはティール塗りのピル型ラベル
- **KPIタイル**: ティール塗り角丸ボックスに白抜きアイコン＋大きな数字（`4,000〜4,500 億円`）
- **STEPカード**: 色分けヘッダー付き角丸カードを横並び、間に `›` 矢印
- **01/02/03**: 大きなティール数字＋線画アイコン＋短い説明（3カラム）
- **まとめ帯**: 下部に淡ティールの角丸ボックスで結論を1〜2行
- **吹き出し**: 「Knownsでポン出し！」のような角丸吹き出しで自社機能をさりげなく訴求
- **章扉**: 白地に右下から淡ティールの山型シェイプ、右上に大きな章番号 `01`、左下にタイトル＋リード文
- **写真**: 人物写真は角丸なしの矩形、もしくは右半分を占める大判。ティールのグラデ背景と組み合わせる
- **事例ページ**: 左に淡グレーの項目ラベル（業界／課題／支援内容／結果）、右に本文の2カラム表
- **出典**: 図の右下に 7pt で必ず記載

### グラフ
- 散布図・レーダー・ファネル・ヒートマップなどを白カード＋薄い影で囲む
- 自社・注目ブランドだけ色を付け、他はグレー
- グラフの右側に「読み解き」テキストを置く（左図・右文）

## 3. スタイル B：エディトリアル＆グラデーション（レポート向け）

### カラー
| 役割 | 色 | HEX |
|------|-----|-----|
| 背景グラデ（暗） | ■ | `#0B0906` → `#2E241C`（黒〜こげ茶） |
| 背景グラデ（暖） | ■ | `#5E2B1C` → `#BC6438` → `#E1C691`（ブラウン〜オレンジ〜ベージュ） |
| 背景グラデ（寒） | ■ | `#356F8B` / `#5B96A1`（ブルーグレー） |
| アクセント（オレンジ） | ■ | `#E2703A` 前後 |
| チャート寒色 | ■ | `#5B96A1` / `#6AA2B6` |
| 見出し帯（ミント） | ■ | `#7CC4B7` |
| 本文ページ背景 | ■ | `#F1F1F1`（ごく淡いグレー＋微細なノイズ） |
| ラベル | ■ | `#0B0906` 黒塗り＋白文字 |

- 本編のデータページは**明るい淡グレー地**、表紙・章扉・総括だけ**暗いグラデーション**にしてメリハリを付ける。
- チャートは **オレンジ × ブルーグレー** の2色対比が基本。

### タイポグラフィ
- 欧文タイトル: **Helvetica Neue**（Bold で極大／Light で章番号・サブ）
- 和文: **Noto Sans JP**、見出しに Zen Kaku Gothic New、情緒的な一言に **Shippori Antique B1**（明朝系）
- 表紙タイトルは英字大文字の超特大（例 `EVENT MARKETING REPORT`）を右寄せで3行積み
- 章番号は Light の細い数字 `01` ＋ その下に進捗インジケーター（`■□□□`）

### レイアウト要素
- **表紙**: 暗背景に大きな円形グラデーション（コニック/放射）を2つ重ねたグラフィック＋特大英字
- **章扉**: 左上 `CHAPTER` ＋細字番号、左下に縦の細線とタイトル（例 `A side / 開催企業視点`）、背景は大きな円弧のグラデーション
- **データページ**:
  - 左上に黒地白文字のタブ型見出し（例「ウェビナー実施の現在地：定着と停滞の同居」）
  - 直下に太字の要約1〜2文（結論先出し）
  - 中央に白カードでグラフ（円グラフ＋横棒グラフの組み合わせが多い）
  - 下部に `Points` 見出し＋解説テキスト
  - 左端に章番号と縦書きの章タイトル（ランニングヘッド）
  - 右下に `EVENT MARKETING REPORT #2　ページ番号`
- **示唆ページ**: 上部をミント `#7CC4B7` の帯にし、黒ラベル「示唆」＋見出し。STEP 01〜04 の構造図を矢印でつなぐ。結論は黒の角丸ピルで白抜き
- **まとめ / Summary**: オレンジ背景に白カードを積み、番号付きで要点列挙
- **メッセージスライド**: グラデ背景の中央に1行コピーのみ（例「顧客のシナプスに、残る言葉を。」）
- **事例**: 写真を大きく複数枚コラージュ＋見出しコピー＋2カラム解説
- **商品比較**: 2カードを横並び、各カードにロゴ・ターゲット・文脈設計をラベル付きで

## 4. 文章・コピーの作法（両資料から抽出）

- **見出しは「主張」で書く**。名詞止めのラベルではなく、結論を言い切る
  - ✕「市場規模」 → ○「市場は拡大。だが、伸びている理由はひとつではない」
- **対比構文**を多用：「〜だけでは〜見えない」「AではなくBだ」「Xから Yへ」
- **問い→答え**：「どこで顧客が逃げているのか？」→ ファネル分析
- 冒頭で顧客の痛みを**口語の一言**で刺す：「面白いけど、根拠は？」
- 数字は大きく単位は小さく（`34.1%`、`4,000〜4,500 億円`）
- 1スライドの本文は3〜5行まで。詳細は注釈か別ページへ
- 締めはエモーショナルなミッション文＋余白の多いビジュアル

## 5. 作成時チェックリスト

- [ ] スタイル（A / B / A+Bハイブリッド）を最初に決めたか
- [ ] 1スライド1メッセージ、キャッチが主張になっているか
- [ ] 使用色はメイン1色＋アクセント1〜2色に収まっているか
- [ ] フォントは和文1系統・欧文1系統（＋情緒用1）に絞ったか
- [ ] 章扉で章番号とリード文を入れ、全体の現在地がわかるか
- [ ] グラフは注目対象だけ色付け、出典を記載したか
- [ ] 結論帯／Points で各ページの「だから何？」を明示したか
- [ ] フッター（ロゴ・コピーライト・ページ番号）が揃っているか
- [ ] 最後に CTA（次のアクション）があるか
