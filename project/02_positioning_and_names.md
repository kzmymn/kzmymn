# STEP 2 ポジショニング ／ STEP 3 チャンネル名

## STEP 2 狙うジャンルとポジショニング

### 結論
**「失われた世界を、大人のための映画として見せる」日本語チャンネル**として立ち上げます。
1つのジャンルに絞らず、「子どもの頃のロマン」という一つの世界観でまとめます。最初の10本の比重は **海（メガロドン・深海）と古生物を中心に、宇宙と古代は1本ずつテスト**とします。

### 理由（調査結果から）
1. **日本語圏には「映画的な映像 × 学術的な厳密さ × 大人向けのナレーション」の席が空いている**
   日本語の競合は、合成音声と静止画の解説がほとんどです。量産型は失速しており（1,189本で直近の平均8,700回の例）、本数より質で勝つ例が出ています（39本で870万回など）。
2. **英語圏の定番テーマは飽和している**ので、最初から英語で戦わない
   ただし映像は言語に依存しないので、**同じ動画に英語の音声トラックを追加する**形で後から海外に広げます。チャンネルを分けないので運営は複雑になりません。
3. **「AIだけど考証が厳密」は、今いちばん価値のある差別化**
   2025〜2026年にかけて、AI歴史動画の不正確さへの批判報道が続き、YouTube も量産型の収益化を止めています。「事実／推定／もしも」を毎回画面に出すことが、そのままブランドと規約対策になります。
4. **海と古生物はAI映像と相性がいい**
   水中は青い霞や粒子でAIの破綻が目立ちにくく、スケール感も出しやすいです。陸上の恐竜は足の接地や羽毛の考証で粗が出やすいので、後半に回します。

### ポジショニングマップ
```
                  映像の質：高い（映画的）
                          │
      英語圏の大手         │   ★ このチャンネル
   （Kurzgesagt, PBS Eons,  │  （日本語・考証が厳密・映画的・大人向け）
     melodysheep）          │
 ──────────────────────────┼────────────────────────── 考証：厳密
   考証：ゆるい              │
    AIスロップ・量産         │   日本語のゆっくり解説
   （見せ物・誤りが多い）    │  （考証は中程度・映像は簡素）
                          │
                  映像の質：低い（静止画＋合成音声）
```

### チャンネルの約束（ブランドの核）
- **テーマ**: 子どもの頃に図鑑で見た世界を、大人の目で、もう一度。
- **毎回やること**
  1. 画面に【事実】【推定】【もしも】のラベルを出す
  2. 概要欄に論文と出典を載せる
  3. 「最新研究で何が変わったか」を必ず1つ入れる
  4. 日本とのつながり（日本の化石、日本の海、日本の研究者）を可能な範囲で入れる。英語圏にはない、日本語チャンネルだけの価値になる
- **やらないこと**: 「実在する」と誤解させる演出、残酷な描写、煽りタイトル、同じテンプレートの量産

### フォーマット（10本で試す4つの型）
| 型 | 内容 | 例 |
|---|---|---|
| A. もしも検証 | 事実を固めてから、「もしも」をシミュレーションする | もしメガロドンが今の海にいたら |
| B. その日・その場所 | ある1日・ある場所に視聴者を立たせる没入型 | 小惑星が落ちた日、ポンペイ最後の日 |
| C. スケール体験 | 深さ・大きさ・時間を体感させる | 1万mの海溝へ降りる、史上最大の生き物を並べる |
| D. 日本のロマン | 日本の化石・海・研究を入口にする | 氷河期の日本、ダイオウイカを初めて撮った日本人 |

### 尺の方針
- 本編は **7〜12分**から始める（制作負荷と視聴維持のバランス）。最初の数本は7〜8分。
- 伸びた型ができたら、**本編を再編集した睡眠用の長尺（60〜120分）**を足す。調査では、小規模チャンネルでも睡眠用ドキュメンタリーがブレイクしています。ただしこれは10本のテストの後に回します。

## STEP 3 チャンネル名候補（10案）

条件: 覚えやすい／日本語と英語の両方で通じる／ジャンルを狭めない（恐竜・海・宇宙・古代を全部含められる）／大人っぽい

### 推奨
- **第1候補: 「夜の図鑑 / The Night Atlas」**
  「子どもの頃の図鑑」と「大人が夜に見る」の両方が一語で伝わります。将来の電子書籍・図鑑・ポスターといった商品展開にもそのまま使えます。
- **第2候補: 「太古シアター / Deep Time Theater」**
  映画的な映像を前面に出すならこちらです。
