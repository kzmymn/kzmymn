## 10本テストの分析計画

### 見る指標と目安
| 指標 | 見るタイミング | 目安（新チャンネルの長尺） | 低かったときに疑うこと |
|---|---|---|---|
| インプレッションのクリック率 | 公開48時間後と7日後 | 4〜6%で合格、8%以上なら強い | タイトルとサムネイル |
| 30秒時点の視聴維持率 | 7日後 | 70%以上 | 冒頭のフック、タイトルと中身のずれ |
| 平均視聴率（維持率） | 7日後 | 40%以上（7〜8分の動画） | 中盤の展開（どこで落ちているかを維持率グラフで見る） |
| 平均視聴時間 | 7日後 | 3分以上 | 同上 |
| 登録率（1,000回あたり） | 28日後 | 5人以上 | 「次も見たい」と思わせられているか（エンディング、シリーズ化） |
| 流入経路 | 28日後 | おすすめ（ブラウジング・関連動画）が増えているか | 検索だけに頼っていないか |
| コメント | 毎回 | 「次は〇〇を」という要望の数 | 次の企画の材料にする |

> 新しいチャンネルの最初の数本は、インプレッション自体が少なく、数字がぶれます。1本で判断せず、**3本ごとに傾向を見ます**。

### 判断のルール
- 10本のうち、**クリック率と平均視聴率の両方が上位3本に入った型（A〜D）**を「勝ち型」とします。11本目以降はその型を中心に作ります。
- 平均視聴率は高いがクリック率が低い → 中身は良い。タイトルとサムネイルを作り直してテストする（公開済みの動画でも変えられる）。
- クリック率は高いが平均視聴率が低い → 期待と中身がずれている。冒頭の作りを見直す。
- 伸びた動画が出たら、**同じ型の次の企画を2週間以内に出す**（おすすめに乗っている間に続ける）。

### 分析のやり方
- 公開から7日後と28日後に、YouTube Studio の「詳細モード」で各指標を CSV に書き出し、共有してください。こちらで比較表を作り、次の改善点を提案します。
- 維持率グラフのスクリーンショットも共有してもらえれば、どのカットで離脱したかを台本・カット表と照らし合わせて特定します。

### 10本の後（勝ち型が見えてから）
1. 勝ち型の制作手順をテンプレート化する（台本の型、プロンプト集、編集プロジェクトの雛形）。ただし中身は毎回変える（量産と判断されないため）
2. 英語の音声トラックを追加する（ElevenLabs で自分の声をクローン、または YouTube の自動吹き替え）
3. 睡眠用の長尺（本編を再編集した60〜120分）を出す
4. 収益化の要件（登録者1,000人、総再生時間4,000時間）に到達したら、メンバーシップ、デジタル図鑑（PDF・電子書籍）、ポスターを検討する

## 収益化の考え方（今は複雑にしない）
| 時期 | やること |
|---|---|
| 今〜10本 | **YouTube の動画だけに集中する。** 収益の仕組みは作らない |
| 登録者500人前後 | メンバーシップなど（YouTube の「ファンファンディング」）が使えるようになる。まだ始めなくてよい |
| 収益化の要件達成後 | 広告収益。概要欄に関連書籍のアフィリエイト（図鑑、博物館の図録など。PR表記を必ず入れる） |
| 勝ち型が固まった後 | デジタル図鑑（PDF）、ポスター（印刷を外部に任せる形）、英語の音声トラックで海外のRPMを取りにいく |
| 規模が出たら | 博物館とのコラボ、教育・科学系のスポンサー |

> **注意（要原文確認）**: 2027年2月1日から、新規申請者の収益化要件が「総再生時間8,000時間」に引き上げられると報じられています。現在の要件（4,000時間）で申請できるうちに届くかどうかで、収益化までの距離が倍変わります。これも、Shortsより長尺動画を主軸にする理由の一つです。
