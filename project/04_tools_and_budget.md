# STEP 11 必要なAIツールと最小限の費用

詳細（比較表・出典）: `research_raw/05_tools_costs.md`
価格は2026年10月時点の二次情報をもとにした概算です（1ドル＝150円換算）。**契約前に必ず公式の料金ページで確認してください。**

## 使わないもの（2026年に状況が変わったため）
- **OpenAI Sora**: アプリは2026年4月、APIは2026年9月に終了
- **Udio**: 2025年10月からダウンロードできず、BGMに使えない
- **にじボイス**: 2026年2月にサービス終了
- **CapCut**: 本編の編集には使わない（素材ごとに商用利用の可否が違い、規約上の懸念がある）

## Ep.01 を作るための最小構成（初月 約1.4万円）

| 工程 | ツール | 月額（目安） | 使い方 |
|---|---|---|---|
| リサーチ・台本 | Claude（このプロジェクト） | 契約中のもの | 調査、台本、カット表、プロンプト、概要欄 |
| 画像（デザインシート、静止画、サムネイル） | **Google AI Pro**（Nano Banana Pro、Gemini） | 2,900円 | MEG_REF などの参照画像、[S] の静止画、サムネイルの背景 |
| 動画（参照画像から動画＝生物の一貫性） | **Kling 3.0 Pro** | 約4,900円（$32.56、3,000クレジット＝1080p無音で約375秒） | [K] の16カット。メガロドンが映るカットはすべてこれ |
| 動画（風景・環境カット） | **Veo 3.1 Fast（API の従量課金）** | 約5,400円（$0.12/秒 × 約300秒） | [V] の16カット。透かしなし。API が難しければ Kling のクレジットを追加して代替 |
| ナレーション | **自分の声**（推奨）または **ElevenLabs Starter** | 0円／約900円 | 下の「決めてほしいこと」参照 |
| BGM・効果音 | YouTube オーディオライブラリ | 無料 | Content ID の問題がない。効果音が足りなければ ElevenLabs の効果音生成 |
| 編集・色・字幕 | **DaVinci Resolve（無料版）** | 無料 | 編集、LUT、グレイン、テロップ、書き出し |
| サムネイルの文字入れ・図解 | Canva（無料版） | 無料 | テロップ素材、図解、サムネイル |
| 分析 | YouTube Studio、vidIQ（無料版） | 無料 | 公開後の分析、外れ値動画の調査 |
| **合計** | | **約1.3万〜1.4万円** | 動画1本あたり約1.1万円が目安 |

> Veo について: Google AI Pro プランの Flow で作った動画には、目に見える透かしが入るという情報があります（Ultra プランか API なら入らない。確度は中）。ドキュメンタリーの画面に透かしが入るのは避けたいので、Veo は API で使う前提にしています。API の使い方は、必要になったらこちらでスクリプトを用意します。

## 2本目以降（月2〜4本作るようになったら）
| 段階 | 構成 | 月額目安 |
|---|---|---|
| 月2本 | 最小構成＋Kling を Premier（$80.96、8,000クレジット）へ | 約2万円 |
| 月4本・品質重視 | Google AI Ultra（Veo を透かしなしで大量に使える。初回3か月は割引）＋Kling Pro＋Epidemic Sound＋ElevenLabs Creator（英語版の音声用） | 約6万円 |

- **費用を上げる条件**: 10本のテストで「伸びる型」が見えてから。それまでは最小構成のまま、生成のやり直し回数を減らす工夫（デザインシートの固定、良いプロンプトの記録）で品質を上げます。

## ナレーションについて（決めてほしいこと）
| 選択肢 | 長所 | 短所 |
|---|---|---|
| **A. 自分の声で録る（推奨）** | YouTube の「inauthentic content」対策として最も強い（人間の作家性がはっきりする）。ブランドになる。費用ゼロ | 録音環境（USBマイク 約1万円、静かな部屋）が必要。慣れるまで時間がかかる |
| B. ElevenLabs v3 の日本語音声 | すぐ始められる。品質は年々上がっている | 同じAI音声のチャンネルが多く、差別化しにくい。声の権利と規約を確認する必要がある |
| C. Aで録り、英語版は自分の声のクローン（ElevenLabs）で作る | 日本語の作家性を保ちつつ、海外展開も楽になる | 月$22程度の追加費用 |

**推奨は A（将来は C）です。** 1本目だけ B で出して、2本目から A に切り替えることもできます。

## 権利・規約のチェックリスト（毎回）
- [ ] 各ツールの有料プランで生成した（無料プランは商用不可・透かし入りのものが多い）
- [ ] BGM・効果音の出典とライセンスを記録した
- [ ] 実在の人物（研究者など）の顔や声をAIで作っていない
- [ ] 他人の復元画（パレオアート）を参照画像に使っていない
- [ ] 論文や博物館の図版を無断で転載していない（自分で描き直すか、許可を取る）
- [ ] NASA などの画像を使う場合は、クレジットを表示し、ロゴは使わない
- [ ] YouTube の「改変または合成コンテンツ」を「はい」にした
- [ ] プロンプト、シード値、使ったツールを `production_log` に記録した（権利について問われたときの証拠になる）
