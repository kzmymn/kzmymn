# Ep.01 AIナレーション用テキスト（ElevenLabs にそのまま貼る版）

`02_script.md` の内容を、**AI音声が読み間違えやすい数字・読みをかなに置き換えた**ものです。内容は台本と同じです。
- 章ごとに1回ずつ生成する（長文を一度に入れると抑揚が崩れやすいため）。全8ブロック。
- 「……」は1〜2秒の間を表す。生成後に間が短ければ、編集で無音を足す（DaVinci で調整するほうが確実）。
- 読み間違いが出たら、その部分だけかなに直して再生成する。直した箇所は下の「読みの置き換え表」に追記していく（次回以降も使い回す）。

## 音声の設定
| 項目 | 設定 |
|---|---|
| ツール | ElevenLabs（Eleven v3 モデル、日本語）。プランは Starter 以上（商用利用可） |
| 声 | Voice Library から、**落ち着いた低めの日本語ナレーター声**を3〜5人試聴して1つに決める。「documentary」「narrator」「calm」「Japanese」で検索。**商用利用が許可された声だけ**を使う |
| 固定 | 決めた声は**全エピソードで変えない**（チャンネルの「声」になる。毎回変えると量産品に見える） |
| Stability | 中くらい（Natural）から始める。抑揚が大げさなら上げ、平板なら下げる |
| 速度 | 1.0を基準に、1秒あたり約5.9字（本編8分前後）に収まるよう微調整する |
| 書き出し | WAV（または最高品質のMP3）。章ごとに `ep01_N01.wav`〜`ep01_N08.wav` |

> 代替: ElevenLabs の日本語が合わない場合は Fish Audio などを試す。VOICEVOX はクレジットの表記が必須で、ドキュメンタリーの語りには不向き。にじボイスは2026年2月にサービス終了。

## N03 【1:03–2:20】第1章「私たちは、全身を見たことがない」
```

私たちは、メガロドンの全身の骨格を、一度も見たことがありません。
サメの骨格は、そのほとんどが軟骨。
```

## N04 【2:20–3:56】第2章「描き変えられた姿」
```
長いあいだ、メガロドンは「巨大なホホジロザメ」として描かれてきました。
太い胴体に、大きな頭。
映画やゲームで、おなじみの姿です。
ところがにせんにじゅうよねんと、にせんにじゅうごねん、研究者たちが別の可能性を示しました。
現生と化石のサメ、ひゃくろくじゅうご種の体のつくりを比べた結果――
メガロドンは、ホホジロザメよりもずっと細長い体をしていた可能性が高い。
その推定では、ベルギーの個体は全長およそじゅうろくメートル。
そして、いまの化石記録から考えうる最大のものは、およそにじゅうよんメートル。
テニスコートの長さと、ほぼ同じです。
生まれたときの体長は、すでにさんてんろくメートルから、さんてんきゅうメートル。

歯の化学分析からは、さらに二つのことがわかってきました。
一つは、体温。
メガロドンの体は、まわりの海水よりなな度ほど温かかったと推定されています。
もう一つは、食物連鎖の中での位置。
歯に残された窒素の記録は、メガロドンが、これまでに知られている海の生き物の中で、最も高い位置にいたことを示しています。
捕食者を食べる捕食者を、さらに食べる。
それが、メガロドンでした。
```
